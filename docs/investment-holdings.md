# 持仓明细

使用 BoardUI Table（React Aria 原生排序交互）、Input 和 Meter。七列依次为股票代码、持仓股数、平均成本、价值、浮盈/浮亏、总回报、资产配置占比。浮盈/浮亏和总回报均为上下两行：上行金额、下行比例，两列按金额排序。资产配置占比使用进度条加百分比数字，缺少分母时不显示进度条。点击列头切换升序、降序，键盘可聚焦后按 Enter 排序；代码按自然顺序、数字按数值排序，缺失值在两个方向都置底。默认代码升序。

外观采用白色圆角表格卡片、浅灰通栏表头、细行分隔线与舒展行距。顶部显示持仓数量与圆角搜索框，盈亏使用 BoardUI Chip 浅绿／浅红标签（保留正负号），缺失值仍显示「—」。颜色使用语义 token，深色模式自动适配。

搜索匹配代码和名称，忽略大小写与首尾空白。它只过滤显示的行，不重算资产配置占比；占比分母仍为所选账户／框架视图总资产（含现金）。手机保留所有列，表格内部横向滚动。

平均成本使用 `buyInPerShare`，价值使用 `valueUsd.value`，浮盈/浮亏金额和比例分别使用 `pnlAmount`、`pnlPct`。可选 `positions[].totalReturn` 为同一持仓核算范围截至快照日的总回报金额（USD，含未实现、已实现收益、分红及费用，避免重复计入），`totalReturnPct` 为同口径的总回报百分比（例如 12.5 表示 12.5%）。两者由数据提供方分别填写，不用浮盈/浮亏代替、不从组合年度回报分摊，也不以平均成本推算总回报比例；金额和比例分别处理缺失或 null，显示「—」，真实零显示 US$0.00 或 0%。平均成本缺失同样不从其他字段反推。公开示例未补造总回报。
