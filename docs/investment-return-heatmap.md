# 收益热力图

默认展示日度月历，可通过「日度 / 月度」切换到原有月度矩阵。日度默认选择数据中最新月份，月份选择在切换后保留。全组合数据不跟随账户、持仓或净值范围筛选。

- `dailyReturns?: { date: "YYYY-MM-DD", returnPct: number | null, pnlAmount?: number | null }[]`：每天最多一条，收益率使用百分点，例如 `0.4` 表示 `+0.4%`。`pnlAmount` 为当天盈亏金额。日期必须有效，数值必须有限。
- `monthlyReturns` 保持原有年份与十二个月的格式，直接显示提供的月收益率；可选 `pnlAmounts` 数组须含十二个金额或 `null`，按一月至十二月对齐。
- 日度和月度分别按其全部已提供数据的绝对最大值分四档，正负同尺度。零收益与缺失值分开显示；日度未提供的日期及显式 `null` 显示「—」。
- 两种粒度使用各自提供的数据，不从月收益拆分日收益，也不将可能含资金流入流出的净值变化当作日收益。示例日数据仅用于演示，不用于复算示例月度收益。
- 旧数据仅有月度时，默认日视图提示「暂无日度收益数据」，切换月度即可查看；两种数据都为空时隐藏卡片。
- 切换粒度与月份时淡入淡出并平滑调整容器高度；系统启用减少动态效果时立即切换。
- 日度和月度格子悬停或键盘聚焦时显示对应日期 / 月份及金额，按金额正负标注「盈利」「亏损」，零标注「持平」。金额使用模块 `currency`（目前为 USD），带正负号及两位小数，例如 `盈利 +USD 1,800.50`、`亏损 −USD 1,355.40`、`持平 +USD 0.00`。未提供金额或为 `null` 时显示「暂无盈亏金额」，不从收益率、当前净值或其他口径推算。
- 提示使用 BoardUI Tooltip，浮层挂载至页面顶层并自动避让视口边缘，避免被横向滚动或动画容器裁切；鼠标移出、焦点离开、Escape 或切换视图时关闭。
