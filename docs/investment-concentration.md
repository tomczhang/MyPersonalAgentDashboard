# 投资组合集中度

使用 BoardUI 官方 `scatter-chart-card` 源码，扩展了应用标题、提示浮层、空态和图例数值插槽。宽屏与收益热力图并排，窄屏上下排列。

## 口径

- 每个气泡代表一个投资标的，同一 `symbol` 跨账户持仓合并市值；遵循页面账户 / 仅框架内筛选。只绘制数量、市值均大于零的持仓。
- 横轴：所选区间的年化波动率（%）；纵轴：同一区间的标的累计收益率（%）。两者均使用百分点，`5.2` 代表 `5.2%`，零和负收益正常展示。
- 面积：快照时点的持仓市值（USD），与筛选区间无关。Z 轴采用 `[0, 最大市值] → [0, 1800]` 的线性面积比例，半径取 `sqrt(面积 / π)`，无最小气泡面积偏置。跨范围保持同一市值比例。
- 标题数字：最大单一标的市值 / 当前筛选下全部持仓市值。不是组合收益率，也不是现有 KPI 的前三大持仓占比；没有可比历史值时不显示变化徽标。
- 中文图例区分股票、基金、债券、加密资产、其他资产；每类颜色固定，图例占比为该类已绘制标的市值 / 当前筛选下全部持仓市值。存在未绘制标的时图例占比之和可能小于 100%。

## 数据入口

`holdings[]` 或 `positions[]` 可添加 `riskReturn`，以 `YTD`（默认年初至今）、`1M`（近1月）、`1Y`（近1年）、`Max`（全部时间）为可选键：

```json
{
  "riskReturn": {
    "YTD": { "volatilityPct": 24.6, "returnPct": -8.4 },
    "1M": { "volatilityPct": 21.1, "returnPct": -2.1 }
  }
}
```

区间截至模块 `meta.asOf`。数据提供方计算区间累计总收益率及基于该区间日收益率、统一按 252 个观测日年化的波动率；前端不从当前盈亏比例、净值或风险评分推算。`Max` 从该标的可用收益历史起点开始。不同数据源须先统一收益及年化口径。

指标允许 `null`；波动率不得为负，两项指标必须为有限数。旧数据可不提供整个字段。缺少所选范围指标、同一标的多条记录指标不一致或分类冲突时，列出标的并跳过绘制，不填零，不回退至示例。最大持仓占比仍使用全部持仓市值。

悬停 / 键盘聚焦提示标的名称、波动率、标的收益率及持仓市值。提示使用 BoardUI Tooltip 顶层浮层，自动避让视口边缘；离开、Escape、切换范围后关闭。遵循减少动态效果设置。
