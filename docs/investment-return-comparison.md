# 收入与收益率

首屏使用 `AreaChartCard` 的 `overlap` 变体，同一百分比轴展示三组**累计收益率**。从所选范围的首个月起按 `∏(1 + 当月收益率 / 100) - 1` 复利累计，不简单相加，也不从净值或资金流推算。亏损月份仍会真实回撤。原始数据保持月度口径。

新增可选 `returnComparison` 数组，每月最多一条记录。`date` 为该月统计截止日期；`income` 为该月投资收益金额（USD，可负）；`portfolioPct`、`sp500Pct`、`nasdaq100Pct` 分别为组合、标普 500、纳指 100 同月收益率，单位为百分点（2 表示 2%）。三组收益率应使用相同截止日期和收益口径。字段缺失表示未知，不能填写 0 代替缺失。

默认本年至今；可选近 1 月、近 1 年、全部。范围以 `meta.asOf` 为截止日期，按范围内可用的月度记录累计，不能表达日级区间收益。卡头静止时保留该快照年份 `performanceByYear[year].totalReturn` 和 `twrPct`。悬停时显示该月 `income` 及截至该月的组合累计收益率，图例同步显示三组累计百分比；离开后恢复年度卡头和各曲线最新点数值。年度绩效为独立填充字段；示例月度复利结果与虚构年度 TWR 不保证一致。

某条序列在范围内缺失一个月的收益率后，该月及后续累计值保持缺失；整个月份记录缺失时三条曲线均中断。不把缺失当作 0，也不跨缺口连线。切换范围会从新范围重新累计。

旧数据无 `returnComparison` 时可使用 `monthlyReturns` 复利累计组合收益率；月收入和两条指数收益率保持缺失，不借用 `series`（净值）或未命名基准序列。空数组显式表示无收益序列。

公开 `data/examples/investment.json` 中新增的月收入及指数收益率全部为虚构演示值，不代表真实标普或纳指表现。正式数据需由填充方提供，来源和确认状态沿用模块 `meta`。

资产分布圆环从十二点方向按数据顺序顺时针绘制，使用放大的细环，不显示底部图例。中心显示名称、大字百分比、小字 USD 金额：默认为总资产、100% 和总额；悬停色块时为该资产名称、占比和金额。该段平滑外移、其余段淡化，移开复原。色块使用固定的命中区域，避免外移动画导致悬停反复触发。键盘聚焦同样显示明细，失焦或 Escape 复原；触屏可点按色块查看。筛选或分布数据变化时重置并重新绘制。

圆环中心的百分比与金额、收入卡头的金额共用数字滚动动效，约 320ms，从当前显示值平滑过渡到目标值，快速切换时连续衔接。固定两位小数精度，避免整数与小数切换导致倍率跳变；reduced-motion 模式直接显示目标值。圆环读屏内容直接报告最终名称、占比与金额，避免朗读动画中间值。
